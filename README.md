# Diet App

体重・食事・筋トレを記録し、在庫から満腹救済食を選べる個人用Webアプリです。

GitHub Pages: https://fmokutagawa-design.github.io/diet-app/

## 公式メニューデータ

`scripts/update-menus.mjs` が公式栄養情報とイオン横浜新吉田店の弁当・惣菜取扱情報を取得して `external-menus.json` を更新します。GitHub Actionsで毎日JST早朝に実行します。

- 対応済み: マクドナルド、モス、松屋、すき家、吉野家、デニーズ、CoCo壱番屋、ファミリーマート関東、セブン‐イレブン関東、ローソン関東、イオン・トップバリュ（各社公式栄養情報）
- イオン横浜新吉田店: 店舗専用ネットスーパーから弁当・惣菜の商品名、価格、取扱状況を取得。栄養値と照合できた商品のみ救済食として自動推薦
- 栄養未確認の新吉田店商品は、商品名入りのFatSecret検索リンクから候補を探し、現物ラベルを見て登録可能
- 次の対象: しんぱち食堂
- まいばすけっと: トップバリュ公式候補を共用（店舗ごとの在庫は店頭確認）
- クリエイトSD: 栄養値非公開のため、救済食の補充候補として店頭確認方式
- 食堂たんと: 週替わり定食のため、ご飯少なめ／なしの概算クイック記録
- 取得に失敗した場合は直前の正常データを保持
- 公式クローラーでは、公式値がない栄養・価格は推定で埋めず、未取得として表示

## 暴走停止モード

ホーム上部で空腹の強さを選び、「一店舗・一会計・一食」で終了する外食候補を表示します。公式栄養値があるチェーンは最新データを使い、公開値がない店・一般的なラーメン・カツ丼・ビリヤニ等は概算と明記します。

- 普通盛り、一皿、一杯で止まれば成功。大盛り・セット・追加注文・二軒目を避ける
- 選択した一食をそのまま食事ログへ登録
- 登録後3時間は「停止中」とし、二軒目へ行きそうな場合は新しい店を提示せず、帰宅して家の救済食へ誘導
